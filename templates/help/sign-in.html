Sign-in and other apps

Your account

The first visit asks you to create the first account, the Super-Admin, with a password of 8 characters or more, unless APP_USERNAME and APP_PASSWORD are set. Changing the password in Settings → Sign-in and other apps signs out your other browsers and your devices.

DISABLE_AUTH=true turns sign-in off, for setups where a reverse proxy already asks for a login: whoever gets in has the whole app.

Accounts and privileges

PrivilegeMay
Super-AdminEverything, every account. Made at the first start, never removed
AdminThe server's settings and Reset data, and the Standard accounts: add, edit, make Admin, remove. Admins do not change each other
StandardTheir own profiles, Deezer accounts, token and devices; Refresh library, Fix missing metadata, Repair downloads and Clear your profiles

Settings → Users adds an account with a temporary password: its user chooses their own at the first sign-in. Removing one gives its Navidrome and Deezer accounts to another account, or removes them with it. Each account sees its own profiles only, in the picker at the top; an Admin manages another account's in Settings → Accounts → Accounts of.

Forgot your password

Each account has a recovery code, shown once: at the first sign-in, then each time it is made again, in Sign-in and other apps, by an Admin for a Standard, or by the Super-Admin for an Admin. On the sign-in page, Forgot your password? takes the username, the code and a new password, and gives the next code.

The Super-Admin without its code can have the app write a one-time code in recovery-code.txt, in its data folder on the server. It works once, for 15 minutes: only someone who can read the server's files gets it.

Too many failed sign-ins

After 5 failures in 15 minutes, the address waits 30 seconds, then twice as long after each new failure, up to 15 minutes. Failures on one username from everywhere at once wait after 50, so someone guessing from the internet cannot lock you out. Behind a reverse proxy, set TRUSTED_PROXIES=1 (the number of proxies in front of the app) so each visitor's own address is counted, and COOKIE_SECURE=true to keep the session on HTTPS.

The two tokens

TokenUsed byOpens
API tokenOther apps, like CatBoardOnly reading the release feed, checking the library and the version
Listening stats tokenNavidromeOnly sending plays

Each is created in Settings, or set with API_TOKEN (the Super-Admin's) and SCROBBLE_TOKEN. One set in the environment cannot be changed in Settings. Each account of the app has its own API token: it reads the release feeds of the profiles chosen under Profiles CatBoard reads, as one feed.

CatBoard

  1. Create an API token in Settings → Sign-in and other apps.
  2. In CatBoard, Settings → Integrations → Deezer to Navidrome, enter this app's address and the token, then save.
  3. Copy the webhook URL CatBoard shows and paste it under CatBoard webhook here. Send a test checks it.

The app then calls the webhook when the release feed or the library index is refreshed, or when an artist is muted, so CatBoard updates at once.
