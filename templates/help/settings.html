Settings

Saving

The Save settings bar appears when you change something under Music and downloads. Changes apply as soon as they are saved, with no restart. The other sections save on their own buttons.

Folder and performance variables like SCAN_DIRS are only read on first start: after that, change them here. Credentials like DEEZER_ARL or APP_PASSWORD are read on every start and take precedence over what is saved here.

Music folders

The folders indexed as your library, one per line. They are paths inside this container, so each must be mounted.

Navidrome paths

How each folder appears inside Navidrome, so generated playlists point to the right files. Every music folder needs a mapping, the downloads folder included. See Playlists and mixes.

Downloads

The folder for downloads, on this server and not a web address. Left empty, it is the music folder named deezer-dl. The line below it is green when it can be written to.

Performance

Library scan threads per folder2 for a spinning disk, 4 for a fast disk or RAID, 8 for an SSD or NVMe. More than 2 on a spinning disk causes seeks and slows the scan down
Download threadsTracks fetched from Deezer at the same time. Deezer throttles the requests, so a low number is safer
Fix missing metadata threadsFiles handled at the same time. Up to the CPU cores given to the container, about 80 MB of memory each, and 2 on a spinning disk. Files that still need a genre are limited by Deezer's rate, whatever the number of threads
Playlist matching threadsSet it to the number of CPU cores given to the container

Release feed

How often the releases of your favorite artists are checked. It needs a connected Deezer account.

Data files

Where the app keeps its state, and where generated playlists are written. The defaults are fine unless you moved them. The data folder must be a persistent volume, or everything is lost with the container.

Navidrome accounts

The Navidrome users this app works for: the address of your Navidrome, a user name and its password. Navidrome does not accept API keys yet. Test signs in and says whether the user is an admin and which libraries it sees. With Navidrome's database mounted at /import/navidrome, it also finds the user there, so its plays and stars can be told apart.

Your install is the first account and keeps working as before, with its .m3u8 files. Publish as this user… moves its playlists to Navidrome's API, as that user: it first shows what will change, and if Navidrome refuses a playlist, nothing changes. With two accounts or more, a picker at the top of the page chooses the account of this browser; each browser keeps its own. Passwords are encrypted, with D2N_ENCRYPTION_KEY when it is set, and never shown again. See Playlists.

Deezer account

The arl cookie of your account, its plan and country. A free account can add a premium one for the downloads only. See Downloads.

Listening stats

The Navidrome setting to copy and the token it sends plays with. Your history and rebuilds are in the Stats tab. See Stats and recaps.

Library index and Repair downloads

Refresh library and Rebuild from scratch are explained in Library and duplicates. Repair downloads is only needed for files saved by versions 1.10.0 to 1.11.0: see Troubleshooting.

Reset data

Each button needs a second click and cannot be undone.

Clear match resultsPlaylists show every track as not checked
Remove all playlistsAlso removes their covers and match results
Clear duplicate reportThe next duplicate scan starts fresh
Forget duplicate decisionsGroups you already reviewed come back
Reset everythingPlaylists, covers, match results and the library index. Your listening history is kept
