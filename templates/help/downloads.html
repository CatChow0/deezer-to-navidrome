Downloads

How it works

The app downloads from Deezer itself: it fetches the file, decrypts it and writes its tags, cover included. You can download a track, a whole album or an artist's discography, from search, a playlist or the Releases view. A file that already exists is not downloaded again.

Accounts and quality

Downloads use the arl cookie of a Deezer account. To get it, sign in on deezer.com, open your browser's developer tools, and copy the value of the arl cookie into Settings → Deezer account.

The second account is only used for downloads: your mixes and the release feed keep using the first. A free arl is refused in that field.

Country and explicit versions

Deezer serves the catalogue of the account's subscription country, shown next to its badge in Settings. The app does not pick a country: to download from another catalogue, use an account from that country.

  • Explicit or censored. You get exactly the version you clicked.
  • Another release of the same recording. When a release is not available for your account, the app may use another release of the same recording, only if it is explicit exactly when the requested track is. It keeps the requested track's tags, and Activity says "from another release".
  • Only the censored version exists for you. The download fails with a message saying so, instead of silently saving it.

Where files go

<downloads folder>/
├── albums/
│   └── Artist - Album/
│       ├── 01 - Artist Title.flac
│       └── 02 - Artist Title.flac
└── songs/
    └── Artist - Title.flac

The folder is set in Settings → Downloads. Left empty, it is the music folder named deezer-dl. Settings shows the folder actually used, and warns if it does not exist or cannot be written to. Mount it as a volume, or the files stay inside the container.

Following a download

The button and Activity show the progress: Queued while it waits for a free slot, then 42% or 3/14, then Downloaded or Already there.

When some tracks of an album fail, the button shows 13/14 saved and lists the missing ones: click it again to fetch only those.

Settings → Performance → Download threads sets how many run at once. Deezer throttles requests, so a low number is safer.

After downloading

In a playlist, Download missing queues every missing track and marks the rows as Downloaded as they finish. Run Refresh library and a Quick scan afterwards so they count as In library. With automation, the next automatic scan picks them up.

If Deezer changes

Downloads and mixes use a private Deezer service. If Deezer changes it, they may stop working until the app is updated. Search, playlists and the release feed use the public API and are not affected.
