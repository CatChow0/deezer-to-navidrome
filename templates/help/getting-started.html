Getting started

What this app does

It keeps your Deezer playlists and your own music server in step. It matches each playlist against your files, writes playlists Navidrome can read, downloads what is missing, follows new releases, and shows what you listen to.

Long tasks run in the background and show their progress in Activity, on the Dashboard and in Settings, so the rest of the page stays usable. Each one shows how long it has been running, its speed and the time left when it can tell. Cancel stops it cleanly: what is done stays done. The × only hides a task that cannot be stopped, like a download, and it keeps running.

First steps

  1. Settings. Check the music folders and the Navidrome paths, make sure the line under Downloads is green, and connect your Deezer account.
  2. Index your library. Settings → Library index → Rebuild from scratch the first time. Afterwards Refresh library only reads new and changed files.
  3. Add playlists. On the Dashboard, paste a Deezer or Spotify playlist link in Playlists, import a CSV, or follow your mixes with Mixes → Choose mixes.
  4. Scan. Open a playlist and run a Quick scan or a Full scan. It writes the .m3u8 Navidrome imports.
  5. Download what is missing. Download missing in the playlist, or Download on a single row. Then run Refresh library and a Quick scan so the new files count as In library.
  6. Automate. Automation in the playlist scans it on a schedule and can download what is missing each time.
  7. See what you listen to. Set up the Stats tab.

Where to find what changed

The New button keeps the notes of each version, one tab each. A dot appears on it after an upgrade, until you open it.

A badge next to these buttons says when a newer version is available.
