Library and duplicates

The library index

The app keeps an index of your files and their tags, so it can match playlists quickly. It only sees files in the Music folders set in Settings.

Refresh libraryIndexes new and changed files only. Use it after downloads
Rebuild from scratchReads every file again. Use it the first time. Slow on large libraries

Supported formats: .mp3, .flac, .m4a, .aac, .ogg, .opus, .wav, .wv and .mp4.

Finding duplicates

  1. In Your library on the Dashboard, click Find duplicates.
  2. Files are grouped by artist, album, title and version, so a remix or a live take is not a duplicate of the original. Groups are shown per album, with the quality of each file.
  3. Check the files to keep. Keep best copies only picks the best of each group, and Keep every copy keeps all of them.
  4. Quarantine unchecked moves the others to /data/dedup_quarantine/. Delete unchecked removes them.

Your decisions are saved: a group you reviewed stays hidden until a new file appears in it. Last duplicate report reopens the latest result without scanning again.

Quality ranking

The best copy of a group is chosen from its codec, file size and how complete its tags are.

Quarantine

Quarantined files are moved, not deleted, so they still take up disk space. Once you are sure, empty the folder:

docker exec deezer-to-navidrome sh -c 'rm -rf /data/dedup_quarantine/*'
