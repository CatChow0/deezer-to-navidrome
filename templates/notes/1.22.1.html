Nothing changes in the app: this version is about how it is built.

  • Tests before the image. Every build now runs the whole Python test suite in the image before it can be published, as the Android build already did with its own tests. A failing test stops the release.
  • Test results graph. Both test runs leave JUnit reports, so the build page of Jenkins shows the graph of passed, skipped and failed tests, build after build.
  • Update. Pull the new image: there is nothing to change in your settings.
