A full review of the app: files that can no longer be lost, a safer sign-in, and many fixes in downloads, mixes and stats.

  • Nothing lost when two things save at once. The playlists list, the scan results and the settings could be wiped when a scan, a mix and a page saved at the same moment. Every file is now written in one step, under a lock, and a damaged file is set aside (name.corrupt-…) instead of being replaced by an empty one.
  • Duplicates. Applying could remove every copy of a track when the file kept last time had been moved: a group where you keep nothing is now left alone. The quarantine notes where each file came from (manifest.jsonl), and the sizes show again.
  • Navidrome playlists kept. With wrong path mappings, a publication emptied your playlists in Navidrome: they are left as they are, with the reason in Settings. A playlist is only taken away from the app once Navidrome confirms it was deleted.
  • Sign-in. A username with accents can sign in. The page after sign-in always stays on this site. Failed attempts from the internet no longer lock you out: set TRUSTED_PROXIES behind a reverse proxy. Forms posted from another site are refused, even with DISABLE_AUTH.
  • Saved passwords stay home. Testing a Navidrome account only uses its saved password with its own server; moving an account to another server asks for the password again. API keys are never put in an address.
  • Names in every script. Artists and titles in Cyrillic, Japanese, Korean… (Кино, 宇多田ヒカル) now match your library; before, they were never found and downloaded again at every scan. The library's keys are updated at the first start.
  • Downloads. A remix and its original, or track 3 of each disc, get their own file. A discography no longer brings whole compilations along. A track asked twice is downloaded once, and automatic downloads stop asking again for tracks already fetched. A very long title fits the disk.
  • Playlist files. Two playlists with the same name each keep their own .m3u8, a title changed on Deezer keeps its file, and one track outside the path mappings no longer stops the whole playlist.
  • Made for you. When downloads are not possible, Daily Mix+ and Discover wait an hour instead of retrying every 10 minutes, and the other profiles get their turn again. Few seeds no longer give a day without Daily Mix. New tracks are spread through Daily Mix+, and Discover holds one third of new releases, as meant. With automatic decisions off, nothing moves by itself.
  • Stats. The yearly recap of a long history opens in seconds, not half a minute. A track renamed in Maloja is counted once. A Deezer match needs whole words ("Intro" is not "Introspection").
  • Scheduler. Saving Settings during a scan no longer starts a second scheduler, a daily scan still runs when the container restarts every night, and one error no longer stops the automatic scans until a restart.
  • Docker. PUID / PGID run the app as your user instead of root. The image uses a fixed Python and fixed library versions.
  • Android app. Signing out clears what the phone saved from the server; tokens are never written to its cache. An update must be this app, signed with the same key and newer: an older build of the same version is never offered.
