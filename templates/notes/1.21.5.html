Fixes found by a code audit.

  • Your own tasks. Activity and the download queue show what you started, and only you or an Admin can stop it. What the app starts itself, like an automatic scan, stays visible to everyone.
  • Download queue. A long queue (a few hundred tracks) no longer drops the downloads still waiting from the list, so asking again does not download them twice.
  • Memory. A track is decrypted and saved as it arrives, instead of being kept whole in memory: several downloads at once need much less.
  • Sign-in. The sign-in takes as long for the account set by APP_USERNAME as for any other, and asking again for the Super-Admin's recovery file keeps the code still valid.
  • Devices. A damaged devices.json is set aside instead of being replaced, which would have signed every phone out.
  • Docker. The image now has a health check: docker ps shows healthy or unhealthy.
  • Update. Pull the new image: there is nothing to change in your settings.
