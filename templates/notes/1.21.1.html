A fix for downloads: the explicit and clean versions of an album, or two albums with one title, are kept apart.

  • Explicit and clean. Both versions of an album have the same title, so they went to the same folder: the second download mixed its tracks with the first's, and skipped those whose file names they shared. The clean version now goes to Artist - Album (Clean), a clean single to Artist - Title (Clean), and their tags carry the album version Clean, so Navidrome shows two albums.
  • Albums with one title. A folder that already holds another release with the same name is left as it is: the new one goes to Artist - Album [Deezer ID]. Downloading an album you already have still fills its own folder.
  • A folder already mixed. Delete it in the downloads folder's albums, then download each version again.
  • Update. The Android app offers this version from your server; nothing changes in it.
