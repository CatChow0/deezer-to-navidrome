Playlists no longer have to come from Deezer. Each track of an imported playlist is matched to a Deezer track, and the playlist then works like any other: previews, Download missing, scans, the .m3u8 and automation.

  • Spotify links. Paste an open.spotify.com/playlist/… link in Playlists. No account or API key is needed, but it only reads public playlists, and the first 100 tracks.
  • CSV files. Import CSV takes an export from Exportify, TuneMyMusic or Soundiiz: any size, private playlists too. A file usually carries each track's ISRC, which gives an exact match.
  • Find on Deezer. Tracks worth a check are marked Review, and the To review filter lists them. Find on Deezer on a row lets you pick the right track yourself, with a preview of each result.
  • Syncing. A Quick scan reads the Spotify playlist again and matches the tracks added since. A CSV import is a snapshot: import the file again to update it.
