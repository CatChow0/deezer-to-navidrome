Repair downloads now sorts the album folders where two versions of an album got mixed before 1.21.1.

  • Mixed folders sorted. Each downloaded file says which Deezer track it is, so its album is known. The files of each release go to the folder a download gives it now: the explicit one keeps Artist - Album, the clean one gets Artist - Album (Clean), another album with the same title Artist - Album [Deezer ID].
  • Missing tracks fetched. Each sorted album is queued again and downloads only the tracks it lacks, shown in Activity.
  • Clean albums apart in Navidrome. Clean albums downloaded before 1.21.1 get the album version Clean in their tags, where they are, so Navidrome does not merge them with an explicit one downloaded later.
  • Nothing deleted. Files saved before 1.11.1 carry no Deezer ID, and a file already in its new folder is never overwritten: they stay where they are. Then run Refresh library and a Quick scan. The button is also in Settings → Library index.
  • Update. The Android app offers this version from your server; nothing changes in it.
