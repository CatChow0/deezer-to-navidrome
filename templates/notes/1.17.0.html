The app gets an API for its Android app: a phone signs in once, with its own token, and can do what the web interface does.

  • Devices. A phone signs in with your account and gets its own token. Settings → Sign-in and other apps lists the devices signed in, with when each was last used, and signs one out, for a lost phone say. A new password signs them all out.
  • API v1. Everything the app needs lives under /api/v1/, described in docs/api/openapi.yaml: answers in one JSON format, reads that say when nothing changed, and long tasks followed without a stream.
  • The whole web interface. Playlists, Releases, search, downloads, the library, Stats, Made for you, the accounts and Settings: each function of the web interface has its counterpart in the API, for the profile the app chooses. The help and these notes are there too.

After the update

  • Behind Authelia or another login proxy, let /api/v1/ through without its login page, or the app cannot sign in: the device's token protects these routes. The README shows the rule for Authelia.
  • Nothing else to do: the web interface works as before.
