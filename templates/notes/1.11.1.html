Downloads from 1.10.0 to 1.11.0 may be damaged

Those versions decrypted the files wrongly: they play with noise and skips, and Navidrome's web player refuses them. Downloads are correct from this version on.

Repair downloads checks every file saved since 1.10.0 against Deezer and replaces only the damaged ones, keeping their tags. Files that are fine, and files it cannot identify on Deezer, are left as they are. Then run Refresh library. The button is also in Settings → Library index.

  • Track id in the tags. New downloads also carry the Deezer id of the track in a DEEZER_TRACK_ID tag.
