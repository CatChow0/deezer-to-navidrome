The library index now keeps up with your downloads, and the duplicate tools are safer.

  • Refresh library, by itself. Once the download list is empty, the new files are indexed one time for the whole batch: no more Refresh library by hand after each download. It shows in Activity as Library refresh (after downloads). It is on by default; turn it off in Settings → Performance → Refresh the library after downloads (or AUTO_REFRESH_LIBRARY=false). The Android app has the same switch in Music and downloads.
  • Duplicates, one scan at a time. Asking for a scan while one runs now follows that one instead of starting another.
  • Duplicates, files changed since the scan. A file replaced after the scan (a better copy dropped under the same name) is left alone, and said so, instead of being moved or deleted.
  • Quarantine. Where a file came from is written before the file moves, so a stop in the middle never leaves a moved file with no known origin.
  • Downloads. The list of finished downloads is trimmed even when nobody opens Activity, and a slow cover or Deezer answer no longer holds a page for long.
  • Update. Pull the new image: there is nothing to change in your settings.
