# Stats Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Stats tab that replaces Wrapped, Maloja and lb-enricher: the app stores its own play history, receives new plays from Navidrome, and shows correct charts and story recaps.

**Architecture:** A SQLite database (`DATA_DIR/stats.db`) holds plays. An import task merges Navidrome and Maloja into it, a ListenBrainz-compatible route receives new plays, and a scheduler job fills gaps from Deezer. One query module serves both charts and recaps, so their numbers cannot disagree.

**Tech Stack:** Python 3 / Flask, stdlib `sqlite3` and `zoneinfo`, `rapidfuzz`, `tzdata`, vanilla ES modules, Jinja templates, stdlib `unittest`.

**Spec:** `docs/superpowers/specs/2026-11-04-stats-tab-design.md`

## Global Constraints

- UI copy in English. Commit subjects for the final release commit follow `Minor - … - V1.13.0`.
- No new runtime dependency except `tzdata`. No npm, no build step, no CDN or Google Fonts.
- Never write to `S:\Wrapped`, `S:\lb-enricher`, `S:\Maloja` or `S:\navidrome`. Real-data checks read copies, in a scratch `DATA_DIR`.
- Merge never deletes a play. Only Start clean can remove plays, and it is refused unless Navidrome's database is available.
- Same play across sources: within 5 s (any title), or within 120 s with the same track key or `rapidfuzz` title similarity ≥ 85. Navidrome's metadata wins.
- Scrobble routes need `Authorization: Token <scrobble token>`, even under `DISABLE_AUTH`.
- Time = plays × track length, labelled as an estimate, with a coverage note when below 100%.
- Escape all names in HTML with `escapeHtml` from `static/js/core.js`.
- Tests never use the real `data/` folder: `tests/__init__.py` sets `DATA_DIR` to a temp folder before anything imports `core.config`.

## Review Focus

Each line has its pinning test in the owning task.

1. **A play arrives during a rebuild:** it waits for the write lock, or gets a 503 so Navidrome retries. It is never lost or answered 200 unsaved (Task 3).
2. **A source is damaged, or Navidrome's schema changed:** a clear error, with `stats.db` unchanged (Task 2).
3. **Bad scrobble payloads:** non-JSON, missing fields, non-integer `listened_at`. No 500s; the valid entries in a mixed batch are kept (Task 3).
4. **Bad query parameters and clock edges:** unknown timezone, malformed key, an empty period, a daylight-saving change. A 400 or empty result, never a 500 or a play counted in two periods (Task 4).
5. **Non-Latin and awkward names:** Japanese titles, `Earth, Wind & Fire`, HTML in a title. Keys stay non-empty and distinct, the comma doesn't split the artist, and the name renders as text (Tasks 1, 7).

- [ ] **Step 4: Implement `core/stats_import.py`**

Order inside `run_import`:
1. Check availability (raises `ImportRefused`).
2. Copy each source's `.db`, `-wal`, `-shm` to a `tempfile` folder in `DATA_DIR`; open read-only; check required tables, naming what's missing; read rows into memory.
3. Update the kept Maloja copy only if the source has at least as many scrobbles. Use the kept copy when the source is absent.
4. Back up `stats.db` with `sqlite3.Connection.backup`; prune to the 3 newest.
5. In one `BEGIN IMMEDIATE` transaction: clear tables for `clean`; re-key existing tracks for `merge`, moving plays when keys collide; apply Navidrome plays, then Maloja plays; fill lengths from the library index; write the report.

Matching against stored plays: sort by time and use `bisect`. Plays from different sources use `same_play`, taking the closest unused candidate. Plays from the same source match only on exact timestamp and track key, except a Navidrome replay of its own play, which matches on exact timestamp alone so that a retag updates it. A Navidrome match replaces the stored play's track, album, length and source; a Maloja match changes nothing. A play whose re-key collides with an identical one (same track and timestamp) counts in `merged`.

Library index: `core.library.load_library_cache(LIBRARY_CACHE_FILE)`, keyed with `track_key` on `tag_artist` / `tag_title`, tolerating a missing file. Expose it as `library_durations() -> dict[str, float]`, cached by file mtime, for Task 3.
